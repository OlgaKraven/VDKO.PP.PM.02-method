Цель

Научиться использовать встроенные утилиты Windows для поиска неисправностей, проверки производительности, анализа ошибок и оценки состояния оборудования. По итогам вы сможете выполнять базовую диагностику без сторонних программ и формировать отчёт.

2.1. Проверка конфигурации и драйверов

Зачем. Диагностика начинается с проверки корректности установки драйверов и распознавания устройств системой.

Шаг 1. Диспетчер устройств

  1. Нажмите Win + X → выберите «Диспетчер устройств».
  2. Просмотрите все категории. Жёлтый восклицательный знак указывает на проблемы с драйвером.
  3. Особенно проверьте:
    • «Видеоадаптеры» — ваша видеокарта;
    • «Сетевые адаптеры» — Ethernet/Wi‑Fi;
    • «Звуковые, игровые и видеоустройства» — аудиоустройства;
    • «Контроллеры USB» — периферия.
  4. Сделайте скриншот общей структуры и проблемных устройств (если есть).
На этом этапе ничего не меняйте — только фиксируйте состояние.

Шаг 2. Информация о драйверах через dxdiag

  1. Нажмите Win + R → введите dxdiag → Enter.
  2. На вкладке «Экран» проверьте название видеокарты и версию драйвера.
  3. На вкладке «Звук» — версию аудиодрайвера.
  4. Если дата драйвера старше года — отметьте в отчёте как «требуется обновление».
  5. Сделайте скриншоты вкладок «Экран» и «Звук».

2.2. Анализ текущей производительности

Зачем. Определяем, ограничивает ли работу системы процессор, память, диск или сеть.

Шаг 1. «Диспетчер задач»

  1. Нажмите Ctrl + Shift + Esc и откройте вкладку «Производительность».
  2. Проверьте:
    • ЦП — текущая загрузка (%);
    • Память — занято/доступно;
    • Диск — активность чтения/записи;
    • Ethernet / Wi‑Fi — скорость приёма/передачи.
  3. Сделайте скриншот с основными показателями.
Если ЦП стабильно > 80–90% — система перегружена. Если Диск ≈ 100% — возможна индексация/обновления.

Шаг 2. Программы автозапуска

  1. Во вкладке «Автозагрузка» отсортируйте по столбцу «Влияние на запуск».
  2. Определите элементы с высоким влиянием, которые не нужны на старте (например, мессенджеры, облачные клиенты).
  3. При необходимости отключите: ПКМ → «Отключить».
  4. Сделайте скриншот отсортированного списка.
Меньше автозагрузок — быстрее запуск системы.

Шаг 3. «Монитор ресурсов»

  1. Нажмите Win + R → resmon → Enter.
  2. Просмотрите вкладки:
    • ЦП — процессы по загрузке;
    • Память — объём, занятый приложениями;
    • Диск — какие файлы читаются/пишутся;
    • Сеть — какие процессы создают трафик.
  3. Сделайте по одному скриншоту каждой вкладки.

2.3. Проверка стабильности и состояния системы

Зачем. Выявляем частоту сбоёв, падений программ, ошибок драйверов и неожиданных перезагрузок.

Шаг 1. Монитор стабильности

  1. Win + R → perfmon /rel → Enter.
  2. Дождитесь графика стабильности, откройте день с ошибками.
  3. Зафиксируйте скриншоты: общий график и карточка одной ошибки.

Шаг 2. Системные события

  1. Win + R → eventvwr.msc → Enter.
  2. Откройте «Журналы Windows» → «Система».
  3. «Фильтровать текущий журнал…» → уровни «Ошибка» и «Критическая» → «ОК».
  4. Сделайте скриншот списка и отдельной записи с подробностями (Источник, Код, Время, Описание).

Шаг 3. Пользовательский фильтр

  1. Создайте представление: «Пользовательские представления» → «Создать…».
  2. Параметры: время — последние 7 дней; уровни — Ошибка/Критическая; журналы — Система и Приложение.
  3. Назовите, например, «Ошибки за неделю» и сохраните. Сделайте скриншот.

2.4. Проверка системных файлов и состояния дисков

Зачем. Повреждённые системные файлы и ошибки тома могут вызывать нестабильность и падения.

Шаг 1. Проверка системных файлов

  1. Откройте «Командную строку» от имени администратора (Пуск → введите cmd → ПКМ → «Запуск от имени администратора»).
  2. Выполните: 
    sfc /scannow
  3. Дождитесь 100% и зафиксируйте результат («Нарушений целостности не обнаружено» или найденные ошибки). Сделайте скриншот.

Шаг 2. Восстановление образа системы (если были ошибки)

  1. В той же консоли выполните: 
    DISM /Online /Cleanup-Image /RestoreHealth
  2. По завершении повторите проверку: 
    sfc /scannow
  3. Сделайте скриншоты с результатами.

Шаг 3. Проверка диска

  1. Выполните команду: 
    chkdsk C:
  2. Изучите сводку (ошибки, состояние диска) и сделайте скриншот.
Если система предложит полную проверку при перезагрузке — согласуйте её после выполнения всех шагов работы.

2.5. Проверка обновлений и драйверов

Зачем. Отсутствие обновлений Windows и старые драйверы часто приводят к зависаниям и снижению производительности.

Шаг 1. Центр обновления Windows

  1. Откройте: «Пуск» → «Параметры» → «Обновление и безопасность» → «Центр обновления Windows».
  2. Нажмите «Проверить наличие обновлений» и дождитесь результата.
  3. Сделайте скриншот с итогами проверки/установки.

Шаг 2. Журнал обновлений в PowerShell

  1. Win + X → «Windows PowerShell (Администратор)».
  2. Выполните: 
    Get-WindowsUpdateLog
  3. Откройте созданный на рабочем столе файл WindowsUpdate.log, найдите по Ctrl + F строки с Error, Install, Warning и сделайте скриншот.

Шаг 3. Карточка драйвера

  1. В «Диспетчере устройств» откройте свойства нужного устройства → вкладка «Драйвер».
  2. Сравните дату драйвера с текущей. Если старше года — зафиксируйте как «к обновлению».
  3. Сделайте скриншот карточки драйвера.
