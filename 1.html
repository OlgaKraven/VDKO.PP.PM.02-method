0. Подготовительные работы

Виртуальная среда VirtualBox, образ Windows 10, установка Recuva и подготовка тестовых данных
Цель 0.1. Средства выполнения работы 0.2. Подготовка виртуальной среды 0.3. Установка Recuva 0.4. Подготовка тестовых данных 0.5. Имитирование удаления данных 0.6. Восстановление в Recuva

Цель

Освоить базовые действия по организации рабочего окружения в среде виртуализации, установке специализированного программного обеспечения и подготовке тестовых данных для проведения эксперимента по восстановлению удалённых файлов.

В результате вы научитесь:

  • работать в виртуальной среде VirtualBox;
  • устанавливать и использовать программу Recuva для восстановления данных;
  • имитировать удаление и успешное восстановление файлов различного типа;
  • документировать каждый этап (скриншотами и краткими выводами).

0.1. Средства выполнения работы

Для выполнения лабораторной работы используются:

Средство Назначение
VirtualBox Среда виртуализации, позволяющая безопасно выполнять действия с системой без риска для основного компьютера.
Виртуальная машина с Windows 10 Рабочая тестовая система, в которой выполняются операции по удалению и восстановлению данных.
Бесплатная программа Recuva Специализированная утилита для восстановления удалённых файлов с дисков, флешек и корзины Windows.

0.2. Подготовка виртуальной среды

Цель

Освоить установку и базовую настройку программы Oracle VM VirtualBox, загрузку официального образа Windows 10 и создание виртуальной машины для безопасного выполнения лабораторных работ.

Зачем это нужно. Работа в виртуальной машине позволяет не повредить основную систему при эксперименте; создавать «чистые» тестовые среды для любых заданий; быстро сбрасывать или клонировать систему; работать без страха ошибиться — всё происходит внутри отдельного контейнера.

Шаг 1. Скачивание и установка VirtualBox

  1. Перейдите на официальный сайт: https://www.virtualbox.org.
  2. Откройте раздел «Downloads» (Загрузки).
  3. Выберите версию для вашей ОС:
    • Windows hosts — если ваш компьютер работает под Windows;
    • macOS hosts — для компьютеров Apple;
    • Linux hosts — для Linux-систем.
  4. Скачайте установочный файл (например, VirtualBox-7.1.x-Win.exe).
  5. Установите VirtualBox: запустите установщик, нажмите Next → Next → Yes → Install, дождитесь завершения, затем Finish.
Если Windows спросит разрешение на установку драйверов сетевого адаптера VirtualBox — выберите Install. После установки зафиксируйте скриншот окна VirtualBox для отчёта.

Шаг 2. Получение установочного образа Windows 10 (через MediaCreationTool)

Зачем. Microsoft чаще предлагает загрузку через официальный инструмент MediaCreationTool.

  1. Откройте сайт https://www.microsoft.com/software-download/windows10.
  2. Нажмите «Скачать средство сейчас» и сохраните файл MediaCreationTool_22H2.exe.
  3. Запустите файл и в приветственном окне нажмите «Принять».
  4. Выберите «Создать установочный носитель (USB‑накопитель, DVD‑диск или ISO‑файл) для другого компьютера» → «Далее».
  5. Проверьте параметры по умолчанию: язык — Русский; выпуск — Windows 10; архитектура — 64‑битная (x64) → «Далее».
  6. Выберите ISO‑файл → «Далее», укажите путь сохранения (например, D:\ISO\Windows10_22H2.iso), дождитесь завершения, затем «Готово».
Важно: теперь у вас есть чистый официальный образ Windows 10, готовый к установке в VirtualBox. Если возникнут сложности со скачиванием, можно воспользоваться резервной ссылкой: Yandex.Disk - https://disk.yandex.ru/d/9Si8gxWRpqmaFA. Обратите внимание, что доступны разные редакции ОС (домашняя и корпоративная), их поведение может отличаться.

0.3. Установка программы Recuva

Зачем. Recuva используется для практического восстановления удалённых файлов — ключевой этап работы.

Шаг 1. Скачивание установочного файла

  1. Откройте браузер внутри виртуальной машины.
  2. Перейдите на сайт разработчика: https://www.ccleaner.com/recuva.
  3. Выберите Free Download (бесплатная версия) и скачайте установщик.

Шаг 2. Установка программы

  1. Запустите скачанный файл rcsetupXXX.exe.
  2. В мастере установки выберите язык «Русский», затем «Далее» → «Установить».
  3. После установки снимите галочку «Запустить CCleaner» (если предлагается) и оставьте включённой опцию «Запустить Recuva».
  4. Завершите мастер — приложение запустится автоматически.
Сделайте скриншот окна мастера установки и рабочего стола с запущенным приложением.

0.4. Подготовка тестовых данных

Зачем. Чтобы проверить работу программы, заранее создайте файлы, которые позже будут удалены и восстановлены.

Шаг 1. Создание папки с файлами

  1. На рабочем столе виртуальной Windows нажмите правой кнопкой мыши → «Создать» → «Папку».
  2. Назовите папку TestFiles и откройте её.

Шаг 2. Создание разных типов файлов

Внутри папки TestFiles создайте несколько документов разных форматов:

  • текстовый файл — note.txt;
  • документ Word — report.docx;
  • изображение (битовая карта) — image.bmp;
  • при желании — таблицу Excel или файл .jpg из папки «Картинки».

Шаг 3. Заполнение файлов содержимым

  • Откройте каждый файл и добавьте короткий текст или картинку для проверки целостности при восстановлении.
  • Сохраните изменения.
Сделайте скриншот папки TestFiles с созданными файлами и их типами.

0.5. Имитирование удаления данных

Зачем. Чтобы протестировать утилиту Recuva, создадим ситуацию «потери данных».

Шаг 1. Удаление папки

  1. Выделите папку TestFiles.
  2. Нажмите Shift + Delete и подтвердите удаление. Либо удалите в корзину и затем полностью её очистите.

Шаг 2. Проверка удаления

  • Убедитесь, что папка TestFiles исчезла с рабочего стола.
  • Проверьте, что корзина пуста.
Для отчёта сделайте скриншот пустого рабочего стола и пустой корзины.

0.6. Восстановление удалённых файлов в Recuva

Зачем. Освоить использование мастера восстановления для поиска и возврата утраченных данных.

Шаг 1. Запуск мастера Recuva

  1. Запустите программу Recuva (через меню «Пуск» или ярлык на рабочем столе).
  2. В приветственном окне нажмите «Далее».

Шаг 2. Указание типа файлов

Выберите тип файлов, которые необходимо восстановить: «Документы», «Изображения» или «Все файлы» (если создавались разные типы), затем «Далее».

Шаг 3. Указание расположения

Выберите «На рабочем столе» или «В определённой папке», укажите путь к прежнему расположению папки TestFiles, затем «Далее».

Шаг 4. Запуск сканирования

Отметьте «Включить углублённый анализ (Deep Scan)» при необходимости полного сканирования. Нажмите «Начать» и дождитесь завершения.

Шаг 5. Анализ результатов

После сканирования появится список найденных объектов. Обратите внимание на статусы пригодности:

  • Отлично (Excellent) — файл можно полностью восстановить;
  • Хорошо (Good) — возможны частичные повреждения;
  • Плохо (Unrecoverable) — файл перезаписан.

Шаг 6. Восстановление файлов

  1. Отметьте нужные элементы (например, note.txt, image.bmp) и нажмите «Восстановить…».
  2. Выберите место для сохранения — новую папку на рабочем столе, например RecoveredFiles.
  3. Не сохраняйте восстановленные файлы в исходное место.
  4. После завершения откройте папку RecoveredFiles и убедитесь, что содержимое совпадает с исходным.
Для отчёта рекомендуется сделать 2–3 скриншота: окно с найденными файлами и статусами, окно выбора папки восстановления, а также содержимое папки RecoveredFiles после восстановления.
