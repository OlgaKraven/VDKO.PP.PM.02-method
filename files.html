2

Открыть образец и формы протоколов

Учебный тестовый комплект образца «Меридиан» показывает способ выполнения. Паспорт образца содержит его контрольные записи.

Папка checks в каждом архиве содержит пустые CSV-формы. Их можно открыть в табличном редакторе; результаты вносятся по собственным действиям. Чистая форма «Отчет о выполнении.docx» содержит оба блока результатов. Заполнение разобрано в конце методики. Результаты образца 00 для сверки открываются после собственного выполнения.

Различить: паспорт и CSV — исходные данные; образец — объяснение; checks — заготовки; собственные отчёты — сдача.

3

Подготовить установщики

  • Oracle VirtualBox — установить на основном компьютере до создания ВМ.
  • Windows 11 x64 ISO — образ учреждения либо официальная ознакомительная редакция; использовать при установке гостевой ОС.
  • PostgreSQL 17.11 для Windows x64 — сервер, pgAdmin и командные инструменты; установить внутри ВМ.
  • DBeaver Community 26.2.4, Windows x86-64 ZIP — извлечь внутри ВМ и запустить dbeaver.exe.
  • PostgreSQL JDBC 42.7.8 — для подключения DBeaver, если драйвер не получен автоматически; Libraries → Add File.
  • Recuva 1.54 — только для дополнительного случая восстановления, устанавливается на системный диск ВМ.

Проверить: установщики получены от разработчиков и соответствуют x64 Windows. При занятии без интернета подготовить их заранее вместе с JDBC-драйвером; отсутствующее скачивание не подменять неработающей ссылкой.
