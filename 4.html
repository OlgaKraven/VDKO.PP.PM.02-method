3. Профилактическое обслуживание оборудования и поддержание его исправности

Очистка системы, проверка дисков, оптимизация автозапуска и служб, обновления, безопасность, резервное копирование и контроль памяти

Цель

Научиться выполнять регулярное техническое обслуживание компьютера и Windows, чтобы продлить срок службы оборудования, предупредить сбои и повысить стабильность работы.

После выполнения вы будете уметь:

  • находить и устранять причины снижения производительности;
  • выполнять чистку программной части (без вмешательства в реестр);
  • поддерживать систему в актуальном и безопасном состоянии;
  • создавать точки восстановления и резервные копии.

3.1. Зачем нужно профилактическое обслуживание

Со временем в системе скапливаются временные файлы и кэш, в автозагрузку добавляются лишние программы, драйверы и службы устаревают — всё это снижает скорость и стабильность.

Регулярная профилактика позволяет:

  • снизить нагрузку на ресурсы;
  • предотвратить перегрев и сбои;
  • освободить место на диске;
  • ускорить запуск системы.

3.2. Очистка системы и проверка дисков

Зачем. Удалим мусорные файлы, проверим диск на ошибки и убедимся в исправности файловой системы.

Шаг 1. Очистка временных файлов (встроенное средство)

  1. Откройте «Очистка диска» через поиск Windows.
  2. Выберите диск C: и нажмите «ОК».
  3. После подсчёта отметьте:
    • «Временные файлы»;
    • «Кэш миниатюр»;
    • «Файлы журнала обновлений Windows»;
    • «Корзина» (если уверены).
  4. Нажмите «ОК» → «Удалить файлы» и создайте скриншот выбранных пунктов.
После очистки перезагрузите компьютер.

Шаг 2. Проверка диска на ошибки (без исправления)

  1. Win + R → cmd → Enter.
  2. Выполните команду: 
    chkdsk C:
  3. Дождитесь результата. Если «Ошибок не обнаружено» — диск в порядке. Иначе зафиксируйте вывод и сделайте скриншот.

Шаг 3. Проверка SSD (если установлен)

  1. В той же консоли выполните: 
    fsutil behavior query DisableDeleteNotify
  2. Интерпретация:
    • DisableDeleteNotify = 0 — TRIM включён;
    • DisableDeleteNotify = 1 — TRIM выключен.
  3. Сделайте скриншот результата.
TRIM помогает SSD корректно очищать ячейки памяти и продлевать срок службы.

Шаг 4. Быстрая проверка состояния дисков

  1. Выполните команду: 
    wmic diskdrive get status
  2. Ожидаемый вывод: по строке OK на каждый диск. Сделайте скриншот.

3.3. Оптимизация автозагрузки и служб

Зачем. Лишние программы в автозагрузке и некоторые службы нагружают систему и замедляют старт.

Шаг 1. Автозагрузка

  1. Ctrl + Shift + Esc → «Диспетчер задач» → вкладка «Автозагрузка».
  2. Отсортируйте по «Влияние на запуск».
  3. Отключите элементы с высоким влиянием, которыми редко пользуетесь (ПКМ → «Отключить»).
  4. Сделайте скриншот списка.
Отключение автозагрузки не удаляет программу.

Шаг 2. Анализ активных служб

  1. Win + R → services.msc → Enter.
  2. Меню «Вид» → «Список», отсортируйте по столбцу «Состояние».
  3. Проверьте службы, которые можно временно остановить, если они не используются:
    • Print Spooler — если нет принтера;
    • Windows Search — индексация может нагружать диск;
    • Bluetooth Support Service — если нет Bluetooth;
    • SysMain (Superfetch) — на слабых дисках может ухудшать отзывчивость.
  4. Сделайте скриншот.

3.4. Проверка обновлений, драйверов и безопасности

Зачем. Актуальные обновления и драйверы повышают стабильность. Проверьте также, что защита включена.

Шаг 1. Центр обновления Windows

  1. «Пуск» → «Параметры» → «Обновление и безопасность» → «Центр обновления Windows».
  2. Нажмите «Проверить наличие обновлений» и дождитесь установки.
  3. Сделайте скриншот результата.

Шаг 2. Драйверы устройств

  1. Win + X → «Диспетчер устройств».
  2. Убедитесь, что нет жёлтых значков. Для примера: ПКМ по устройству → «Свойства» → вкладка «Драйвер».
  3. Если дата драйвера старше года — рекомендуйте обновление. Сделайте скриншот карточки драйвера.

Шаг 3. Антивирус и брандмауэр

  1. «Пуск» → «Параметры» → «Обновление и безопасность» → «Безопасность Windows» → «Открыть Центр безопасности».
  2. Проверьте состояния:
    • «Защита от вирусов и угроз» — включена;
    • «Защита учётных данных» — активна;
    • «Брандмауэр и безопасность сети» — включён для всех сетей.
  3. Сделайте скриншоты.

3.5. Резервное копирование и точки восстановления

Зачем. История файлов и точки восстановления помогают вернуть систему в рабочее состояние после неудачных изменений.

Шаг 1. История файлов

  1. «Панель управления» → «Система и безопасность» → «История файлов».
  2. Если есть внешний диск/раздел — нажмите «Включить». Иначе просто откройте окно и сделайте скриншот.

Шаг 2. Точка восстановления

  1. Win + R → SystemPropertiesProtection → Enter.
  2. Убедитесь, что защита включена для диска C:.
  3. Нажмите «Создать», введите имя (например, Профилактика_ноябрь), дождитесь завершения.
  4. Сделайте скриншот.

3.6. Контроль состояния памяти и производительности

Зачем. Сбои могут быть вызваны неисправной ОЗУ или перегрузкой. Проверим эти параметры.

Шаг 1. Проверка памяти (Windows Memory Diagnostic)

  1. Win + R → mdsched.exe → Enter.
  2. Выберите «Перезагрузить и проверить».
  3. После теста результаты доступны в «Центре уведомлений» или «Просмотр событий → System → MemoryDiagnostics-Results».
  4. Сделайте скриншот.

Шаг 2. Сводный отчёт System Diagnostics

  1. Win + R → perfmon /report → Enter.
  2. Через минуту откроется отчёт. Просмотрите разделы «Сводка системы», «Процессор», «Память», «Диск», «Сеть».
  3. Сделайте скриншот.
Отчёт поможет определить узкие места производительности.
