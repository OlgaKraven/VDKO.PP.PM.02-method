Цель

Освоить встроенные средства Windows для наблюдения за состоянием компьютера — процессора, памяти, дисков, сети, а также за общим уровнем стабильности системы. Научиться понимать, что происходит с ПК прямо сейчас, и вовремя замечать признаки неисправностей.

4.1. Что такое мониторинг

Мониторинг — это постоянное наблюдение за состоянием оборудования и системы. С помощью встроенных инструментов Windows можно в реальном времени отслеживать:

  • загрузку процессора и памяти;
  • активность жёсткого диска и сетевых адаптеров;
  • работу служб и приложений;
  • историю ошибок и предупреждений.

Регулярный мониторинг помогает выявлять перегрузки, понимать причины медленной работы, определять узкие места (ЦП, диск, память, сеть) и предотвращать сбои или перегрев.

4.2. Диспетчер задач (Task Manager)

Зачем. Базовый инструмент для наблюдения за текущей нагрузкой и активными процессами.

Шаг 1. Запуск

  1. Ctrl + Shift + Esc или ПКМ по панели задач → «Диспетчер задач».
  2. Если видите упрощённый режим, нажмите «Подробнее».

Шаг 2. Производительность

  1. Откройте вкладку «Производительность».
  2. Слева доступны разделы: ЦП, Память, Диск, Ethernet / Wi‑Fi.
  3. Наблюдайте за графиками и сделайте общий скриншот.
Если ЦП стабильно > 90% — фоновые приложения мешают работе.

Шаг 3. Процессы

  1. Перейдите на вкладку «Процессы».
  2. Отсортируйте по «ЦП» или «Память», чтобы увидеть наиболее ресурсоёмкие приложения.
  3. Сделайте скриншот с верхними строками списка.

Шаг 4. Автозагрузка

  1. Откройте вкладку «Автозагрузка».
  2. Отключите ненужные элементы (ПКМ → «Отключить»).
  3. Сделайте скриншот.

4.3. Монитор ресурсов (Resource Monitor)

Зачем. Расширенный просмотр использования ЦП, памяти, диска и сети по процессам и файлам.

Шаг 1. Запуск

  1. Win + R → resmon → Enter.

Шаг 2. Анализ ЦП

  1. Вкладка «ЦП» → отсортируйте по «% процессора».
  2. Сделайте скриншот таблицы «Процессы».

Шаг 3. Анализ памяти

  1. Вкладка «Память» → обратите внимание на «Физическая память (используется)», «Commit (запрошено)», «Hard faults/sec».
  2. Сделайте скриншот.

Шаг 4. Анализ диска

  1. Вкладка «Диск» → отсортируйте по «Байт/с», чтобы увидеть самые активные процессы и файлы.
  2. Сделайте скриншот.
Диск часто загружает индексация Windows Search.

Шаг 5. Анализ сети

  1. Вкладка «Сеть» → изучите «Отправка (B/с)» и «Приём (B/с)».
  2. Сделайте скриншот.

4.4. Монитор стабильности (Reliability Monitor)

Зачем. Визуальный анализ ошибок и падений за последние недели.

Шаг 1. Запуск

  1. Win + R → perfmon /rel → Enter.

Шаг 2. Анализ

  1. Синие линии — стабильность, красные крестики — ошибки.
  2. Выберите день с ошибкой, изучите описание и сделайте скриншоты: общий график + карточка события.

4.5. Просмотр событий Windows (Event Viewer)

Зачем. «Чёрный ящик» Windows: все ошибки, предупреждения и системные сообщения.

Шаг 1. Запуск

  1. Win + R → eventvwr.msc → Enter.

Шаг 2. Системные журналы

  1. Откройте: «Журналы Windows → Система», «Журналы Windows → Приложение».
  2. «Фильтровать текущий журнал…» → уровни «Ошибка» и «Критическая».
  3. Сделайте скриншот списка и карточки повторяющейся ошибки.

Шаг 3. Пользовательский фильтр

  1. «Пользовательские представления» → «Создать пользовательское представление…».
  2. Время — последние 7 дней; Уровни — Ошибка/Критическая; Журналы — Система, Приложение.
  3. Назовите, например, «Ошибки недели» и сделайте скриншот.

4.6. Диагностический отчёт системы (System Diagnostics)

Зачем. Сводный отчёт за 1–2 минуты с автоматическими пометками узких мест.

Шаг 1. Запуск

  1. Win + R → perfmon /report → Enter.

Шаг 2. Анализ отчёта

  1. Просмотрите разделы: «Сводка системы», «Процессор», «Память», «Диск», «Сеть».
  2. Жёлтые/красные строки — предупреждения/ошибки. Сделайте скриншот.
  3. Отчёт можно сохранить в HTML (Файл → Сохранить как) и приложить к отчёту.

4.7. PowerShell для быстрого мониторинга сети

Зачем. Быстрый просмотр списка сетевых адаптеров, их состояния и скорости.

Шаг 1. Сетевые адаптеры

  1. Откройте PowerShell от имени администратора (Win + X → «Windows PowerShell (Администратор)»).
  2. Выполните: 
    Get-NetAdapter | Select Name, Status, LinkSpeed
  3. Сделайте скриншот результата.

Шаг 2. Дополнительные свойства (только просмотр)

  1. Выполните: 
    Get-NetAdapterAdvancedProperty
  2. Изучите параметры (энергосбережение, дуплекс, буферы). Ничего не меняйте. Сделайте скриншот.
Если статус адаптера «Disabled», включите его через «Центр управления сетями».

Приложение. Быстрая настройка виртуальной машины VirtualBox

Шаги ниже включены как дополнение для учебной среды.

Шаг 1. Создание новой ВМ

  1. Запустите VirtualBox → «Создать».
  2. Параметры:
    • Имя: Windows10-Lab
    • Тип: Microsoft Windows; Версия: Windows 10 (64-bit)
    • Память: не менее 2048 МБ (рекомендуется 4096 МБ)
  3. Диск: «Создать новый» → VDI → Динамически расширяемый → 30 ГБ.

Шаг 2. Подключение ISO

  1. Выделите ВМ → «Настроить» → «Носители».
  2. В «Контроллер IDE» добавьте ISO Windows 10 и сохраните.

Шаг 3. Установка Windows 10

  1. Старт ВМ → мастер установки:
    • Язык/раскладка → «Далее» → «Установить сейчас»;
    • «У меня нет ключа продукта» → редакция Windows 10 Pro;
    • Принять лицензию → «Выборочная установка»;
    • Выберите созданный диск 30 ГБ → «Далее».
  2. После перезагрузки создайте пользователя (например, Student).
  3. Сделайте «Снимок состояния» (Snapshot) для возврата к чистому состоянию.

Шаг 4. Общая папка (по желанию)

  1. VirtualBox → «Устройства» → «Общие папки» → «Настройки…».
  2. Добавьте папку (например, D:\LabExchange) с опциями «Автомонтировать» и «Только чтение» при необходимости.
