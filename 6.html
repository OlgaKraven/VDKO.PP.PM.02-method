5. Специализированные утилиты для отслеживания показателей производительности ключевых узлов компьютера

Отчёт по энергопотреблению, сетевые адаптеры, журнал обновлений, целостность файлов, состояние дисков и безопасность
Цель 5.1. Отчёт об энергопотреблении 5.2. Сетевые адаптеры (PowerShell) 5.3. Журнал обновлений Windows 5.4. Системные файлы (SFC/DISM) 5.5. Файловая система и накопители 5.6. Служба безопасности Windows 5.7. PerfMon Report

Цель

Научиться использовать встроенные диагностические инструменты Windows для глубокого анализа производительности процессора, памяти, дисков, сети и системных компонентов.

После выполнения студент сможет:

  • создавать отчёты о состоянии системы;
  • выявлять ошибки питания, драйверов и служб;
  • проверять целостность файлов Windows;
  • анализировать историю обновлений и лог ошибок.

5.1. Создание отчёта об энергопотреблении системы

Зачем. Показывает устройства/настройки, мешающие экономии энергии и переходу в спящий режим.

Шаг 1. Администраторская консоль

  1. «Пуск» → введите cmd → ПКМ → «Запуск от имени администратора».
  2. Выполните: 
    powercfg /energy
  3. Ожидайте ~60 секунд, пока идёт анализ.

Шаг 2. Получение отчёта

  1. По умолчанию отчёт сохраняется в C:\Windows\System32\energy-report.html.
  2. Если нет доступа к System32, выполните: 
    powercfg /energy /output %USERPROFILE%\Desktop\energy.html
  3. Откройте созданный HTML и просмотрите разделы:
    • Errors — критичные проблемы;
    • Warnings — потенциальные проблемы (драйверы, активность сети);
    • Information — сведения о параметрах питания.
  4. Сделайте скриншот с датой анализа и количеством ошибок/предупреждений.
Отчёт особенно полезен для ноутбуков: помогает экономить батарею и снижать нагрев.

5.2. Проверка сетевых адаптеров через PowerShell

Зачем. Узнать активные сетевые устройства, их состояние и скорость.

Шаг 1. Открытие PowerShell

  1. Win + X → «Windows PowerShell (Администратор)».

Шаг 2. Команда

  1. Выполните: 
    Get-NetAdapter | Select Name, Status, LinkSpeed
  2. Зафиксируйте скриншот таблицы результата.

Шаг 3. Расширенные параметры (по желанию)

  1. Команда: 
    Get-NetAdapterAdvancedProperty
  2. Изучите параметры (энергосбережение, дуплекс, буферы) и сделайте скриншот.
Если адаптер имеет статус «Disabled», включите его через «Центр управления сетями».

5.3. Проверка журнала обновлений Windows

Зачем. Позволяет выяснить, когда и как устанавливались обновления, и были ли ошибки.

Шаг 1. Создание журнала

  1. Откройте PowerShell (Администратор).
  2. Выполните: 
    Get-WindowsUpdateLog
  3. Файл WindowsUpdate.log появится на рабочем столе.

Шаг 2. Анализ

  1. Откройте файл и выполните поиск (Ctrl + F) по словам:
    • Error — ошибки;
    • Install — успешные установки;
    • Warning — предупреждения.
  2. Найдите по одной записи на ошибку и успешную установку и сделайте скриншот.
Пример: «Failed to install KB5030215».

5.4. Проверка системных файлов (SFC и DISM)

Зачем. Поиск и восстановление повреждённых системных файлов.

Шаг 1. SFC

  1. Откройте «Командную строку» от имени администратора.
  2. Выполните: 
    sfc /scannow
  3. Дождитесь завершения и зафиксируйте результат скриншотом.

Шаг 2. DISM

  1. Если SFC нашёл ошибки, выполните: 
    DISM /Online /Cleanup-Image /RestoreHealth
  2. По окончании повторите: 
    sfc /scannow
  3. Сделайте скриншоты.
Команды безопасны: используют встроённые источники и не влияют на личные файлы.

5.5. Проверка файловой системы и накопителей

Зачем. Ошибки диска — частая причина зависаний и потери данных.

Шаг 1. CHKDSK

  1. Откройте консоль администратора.
  2. Выполните: 
    chkdsk C:
  3. Дождитесь сводки и сделайте скриншот.

Шаг 2. Состояние накопителей

  1. Выполните: 
    wmic diskdrive get status
  2. «OK» по каждому диску означает исправность. Сделайте скриншот.

Шаг 3. TRIM для SSD

  1. Проверьте: 
    fsutil behavior query DisableDeleteNotify
  2. Интерпретация:
    • 0 — TRIM включён;
    • 1 — TRIM выключен.
  3. Сделайте скриншот результата.

5.6. Проверка службы безопасности Windows

Зачем. Убедиться, что защита включена и работает корректно.

Шаг 1. Центр безопасности

  1. «Пуск» → «Параметры» → «Обновление и безопасность» → «Безопасность Windows» → «Открыть Центр безопасности».
  2. Проверьте:
    • «Защита от вирусов и угроз» — включена;
    • «Брандмауэр и безопасность сети» — активен для всех сетей;
    • «Защита устройства» — в норме.
  3. Сделайте скриншоты.

Шаг 2. Журнал защиты

  1. В разделе «Защита от вирусов и угроз» откройте «Журнал защиты».
  2. Проверьте, есть ли обнаруженные угрозы и действия по ним. Сделайте скриншот.

5.7. Проверка производительности (PerfMon Report)

Зачем. Получить системный отчёт с анализом работы оборудования.

Шаг 1. Создание отчёта

  1. Win + R → perfmon /report → Enter.
  2. Подождите около минуты до завершения сбора данных.

Шаг 2. Просмотр результатов

  1. Обратите внимание на «System Summary»: зелёный — всё в порядке; жёлтый — предупреждения; красный — ошибки.
  2. Просмотрите разделы: «Процессор», «Память», «Диск», «Сеть» и сделайте скриншот со сводкой и датой анализа.
  3. Отчёт можно сохранить как HTML и приложить к итоговому документу.
